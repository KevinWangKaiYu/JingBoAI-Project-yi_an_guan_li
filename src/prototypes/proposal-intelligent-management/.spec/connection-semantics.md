# 流程连线语义（截图还原）

本页以 `codex-clipboard-b437d213-e6d2-42a2-8990-be338352e233.png` 为唯一视觉和关系依据；连线不得只作为装饰处理。

| 层级 | 形态 | 起点 → 终点 | 含义 | 动效 |
|---|---|---|---|---|
| L1 阶段链 | 顶部水平白/蓝虚线、途中白色锚点、抵达下一卡前的青色箭头 | 相邻顶部阶段卡 | 管理阶段的先后顺序 | 低频、由左至右的短流光；锚点只呼吸，不位移 |
| L2 阶段映射 | 青色直角虚线：垂直下落 → 水平折返 → 胶囊标签 → 向下三角 | 顶部阶段卡 → 下方泳道入口 | 阶段负责/覆盖哪个执行域；不是从顶部卡跳转到某个任务节点 | 路径分段亮起，胶囊和三角依次淡入；不做连续跑马灯 |
| L3 执行主线 | 下方贯穿节点中轴的青色实线；节点之间带箭头和发光锚点 | 相邻任务节点 | 可执行任务的实际交接顺序 | 连续左至右流光，经过锚点和节点时短暂增强边框光晕 |
| L4 并行分支 | 紫蓝直角实线框；从主线拆分到上下两张支路卡，再在右侧回接 | 任务分发节点 → 监督 / 异常处理节点 → 主线 | 由主线拆出的并行监督和异常处置；不是顺序主链的一部分 | 支路以较慢速度循环；在右侧汇流后再交还主线 |
| L5 生命周期边界 | 底部黄色虚线从首节点下沉，横跨到归档节点前再垂直上升 | 起始节点 ↔ 归档前端点 | 表示整条业务流的纳管/闭环范围；不是业务动作或跳转 | 静态弱闪，不能表现为流向箭头 |
| L0 版面辅助 | 背景网格、半透明泳道边框 | 无 | 仅用于对齐、分区和阅读层级 | 无动效 |

## 关键校正

截图中“议案数据审核”下落的青色直角虚线，先在泳道入口处结束；它不直接指向下方“03 智能预审”卡。实际关系是：**上层阶段 → 下层泳道（归属）**，而该泳道中再由 L3 执行主线串联各具体节点。

## 实现约束

- 六类线必须使用独立的 SVG path、data 属性和动画 class，禁止以一条通用连线复用。
- 阶段映射线不得配置 click handler；可点击的是下方任务节点。
- 并行分支必须绘制拆分与回接两个端点；黄色闭环边界不显示箭头。
- 执行主线的箭头、阶段映射线的三角落点、生命周期边界的端点样式必须分别实现，不能共用一个箭头组件。
- 主线与分支都必须经过独立的发光锚点；连线不可直接贴在卡片边缘，需保留截图中的短间距和光点节奏。
